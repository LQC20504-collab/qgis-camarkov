name=CA-Markov Land Change Prediction
description=CA-Markov land-use change analysis, model training and scenario prediction based on random-forest transition potentials.
about=CA-Markov land change modelling exposed as three Processing algorithms: transfer
 analysis (fast transition-matrix preview), model training (random-forest transition
 potential maps) and multi-step scenario prediction with accuracy assessment.
 The bundled engine runs in a separate Python
 subprocess, so it never loads GDAL into the QGIS process.
 Requires numpy, scipy, scikit-learn, rasterio and matplotlib; QGIS 3.28 or newer
 (validated on 3.40.15 LTR). All input rasters must share the same grid and CRS.
 Outputs: a prediction GeoTIFF, a report, figures and a metrics JSON, shown in a
 dockable five-tab result panel.
